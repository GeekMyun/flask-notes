{%macro input(name,type='text',placeholder='')%} {%endmacro%}

宏macro的使用：

{{input('username','text','输入用户名~')}}

外部引用宏macro:

{% from "day08_1.html" import input,but %}
{{input('text','user','请输入~')}} {{but('submit','提交')}}

另外一种调入：

{% import "day08_1.html" as mf%}
{{mf.input('password','pwd','密码不能为空~')}} {{mf.but('reset','重置')}}

call调用块：

{%macro box()%}
{{caller()}}
{%endmacro%} {% call box()%}

hello world!

{%endcall%}
